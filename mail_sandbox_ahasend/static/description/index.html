AhaSend sandbox for test copies

Copies of a production database, for testing, staging or trying an upgrade, hold the email addresses of real customers. Odoo’s neutralization keeps them from emailing anyone by turning all outgoing mail off, so testers cannot see what Odoo would have sent.

With this module, a neutralized copy sends its email to the AhaSend sandbox instead. AhaSend accepts every email, never delivers it, and shows it in the AhaSend dashboard, with its HTML and text content and its headers. Each email is tagged with the name of the database it came from, so the email of several copies can be told apart.

The copy uses a sandbox SMTP credential that the production database holds. AhaSend never delivers email sent with a sandbox credential, so this credential cannot send real email, also when a database dump with it ends up elsewhere. Every email of a neutralized copy also carries AhaSend’s sandbox header.

The neutralization also removes the AhaSend API key, and the IDs and secrets of the webhook and inbound route, so that a copy cannot act on the production account.

Configuration

To configure this module, you need to:

  1. Set up the AhaSend account in Settings > General Settings > AhaSend, as the AhaSend module (mail_ahasend) describes. To create the credential from Odoo, the API key needs the scope smtp-credentials:write:all, or smtp-credentials:write:{domain} for the sending domain.
  2. In the production database, in the Test copies box, click Create sandbox credential. Odoo creates an SMTP credential in sandbox mode in AhaSend, limited to the sending domain when one is set, and stores its username and password.

To use a credential that you created in the AhaSend dashboard instead, turn on Sandbox for it and fill in its username and password in the same box.

From then on, neutralizing a copy of the database, for example with odoo-bin neutralize, sets up the AhaSend sandbox mail server in the copy.

For a copy that was neutralized before the credential was set, fill in the credential in the copy and click Use the AhaSend sandbox.

Disconnect test copies removes the username and password from Odoo, so that copies made from then on send no email at all, as with Odoo’s own neutralization. The credential stays in the AhaSend account, where you can delete it.

Usage

Use a neutralized copy as usual. The email it sends shows up in the AhaSend dashboard as a sandbox message, with its content and headers, and tagged odoo-<database name>. Nothing reaches the recipients.
