This module connects Odoo to `AhaSend <https://ahasend.com>`__, the
European transactional email service. It holds the AhaSend account
settings and the connection to the AhaSend Management API, which the
other AhaSend modules use:

-  *Mail tracking for AhaSend* (``mail_tracking_ahasend``) shows
   delivery, bounce, open and click events in Odoo's mail tracking.
-  *Inbound email for AhaSend* (``mail_inbound_ahasend``) receives email
   for Odoo's aliases from AhaSend, without a mail server to poll.
-  *AhaSend sandbox for test copies* (``mail_sandbox_ahasend``) sends
   the email of neutralized copies to the AhaSend sandbox, where it can
   be viewed but is never delivered.

On its own, this module adds no feature. Install one of the modules
above.

When a database is neutralized, this module removes the AhaSend API key
from the copy, so that the copy cannot act on the production account.

Configuration
=============

To configure this module, you need to:

1. In AhaSend, verify your sending domain and create an API key. The
   scopes it needs depend on the AhaSend modules you install; each
   module's configuration lists them. Note your account ID and the
   secret key of the API key.
2. In Odoo, go to *Settings > General Settings > AhaSend > Account* and
   turn it on.
3. Fill in the account ID and the secret key. Optionally, fill in:

   -  *Sending domain*: limits the AhaSend features to one sending
      domain.
   -  *Odoo URL*: the public ``https://`` address AhaSend sends events
      and email to. It is filled in with the base URL of this Odoo;
      change it when AhaSend must reach Odoo on another address.

You can set the timeout of calls to the AhaSend API, in seconds, with
the system parameter ``ahasend.timeout`` (default: 10). The system
parameter ``ahasend.api_url`` changes the address of the API, for
testing against another server.

The full setup guide is at https://ahasend.com/docs/guides/odoo.
